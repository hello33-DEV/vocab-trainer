# 词汇工坊 · PDF 词库学习助手

> Vocab Trainer — 一个本地优先（Local-first）的通用单词学习工具。纯前端实现，双击即用，无需安装、无需服务器。

用户可导入自己的 PDF 词库，在浏览器本地完成解析、背诵、练习与统计；具体使用什么词库、学习什么内容，完全由用户自己决定。

## 功能特性

- **PDF 词库导入**：选择或拖拽 PDF，在浏览器本地解析（pdf.js），自动提取「单词 / 音标 / 释义」，预览确认后入库
- **开箱即用**：内置一份示例词库，打开即可开始背诵，也可以随时导入自己的词库
- **卡片背诵**：翻转卡片，按「不认识 / 模糊 / 认识」分级记忆，自动收集需要重学的词
- **多种练习**：拼写回忆、听音辨词等练习模式，即时判断对错
- **发音支持**：浏览器内置系统语音合成（零第三方依赖）；也可将自备发音音频按 `单词.mp3` 命名放入 `assets/audio/`，应用会自动优先使用本地音频
- **学习闭环**：错题本、生词本、词表总览、学习进度统计
- **本地优先**：学习进度与自定义词库全部保存在浏览器 localStorage，离线可用

## 快速开始

1. 用浏览器（推荐 Chrome / Edge）打开 `index.html`
2. 直接背诵内置示例词库，或进入「词库」→「导入 PDF」→ 选择或拖拽你自己的词库文件 → 预览确认 → 入库

无需构建、无需 Node.js、无需任何安装步骤。

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤、无第三方依赖安装
- PDF 解析在浏览器本地完成（pdf.js），词库文件不会上传到任何服务器
- 词库数据为 JSON 格式；自定义词库同样以 JSON 存入浏览器本地存储

## 数据与版权说明

- 内置示例词库为**自行编写的示例数据（约 50 词）**，仅用于演示学习流程，不包含任何第三方词表、词频或词典释义数据
- **本仓库不包含任何 PDF 原文、不附带任何第三方词库数据、不附带任何发音音频文件**；用户导入的词库内容与版权归其来源所有，与本工具无关
- 发音使用浏览器系统语音合成（零第三方依赖）；如需真人发音，请将自备的发音音频按 `单词.mp3` 命名放入 `assets/audio/` 目录，应用会自动优先使用本地音频
- 请在符合当地法律法规的前提下使用自备的词库资料
